# MD 编辑器 (MD_Editor)

一款轻量级、支持实时预览与 GitHub 图床集成的 Markdown 编辑器。

---

## 🚀 主要功能

* **双栏实时预览**：所见即所得，流畅的编辑体验。
* **GitHub 图床集成**：支持图片一键上传，自动生成链接。
* **自动保存**：内置防丢失机制，守护你的灵感。
* **轻量化设计**：界面简洁，响应迅速。
